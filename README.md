## Описание курса

«Матричные вычисления МФТИ 2026» — курс по численной линейной алгебре. В курсе рассматриваются матричный анализ, малоранговые приближения, задачи наименьших квадратов, прямые и итерационные методы решения линейных систем, вычисление собственных значений, структурированные матрицы и тензорные разложения.

Курс разделен на две части: избранные темы матричного анализа (лекции 1-11) и введение в тензорный анализ (лекции 12-14).

## Оценка

Итоговый балл складывается из следующих компонентов:

- **50% — итоговый устный зачёт;**
- **20% — короткие письменные тесты на каждом занятии;**
- **30% — домашние задания.** Баллы за домашнее задание учитываются только после его устной защиты;
- **до 10% дополнительных баллов — бонусные домашние задания.**

Итоговый балл вычисляется по формуле

`Итоговый балл = 0.5 Зачёт + 0.2 Тесты + 0.3 Домашние задания + 0.1 Бонус`

Бонус не входит в базовые 100% и может добавить к итоговому результату до 10 процентных пунктов. Итоговая оценка не может превышать 10 баллов.

**Теоремы и результаты:** Векторизационно-кронекеровское тождество для произведения трёх матриц; тождество векторизации тензора Таккера; тождества для развёрток тензора Таккера; эквивалентность представлений Таккера и развёрток; минимальные ранги Таккера как ранги развёрток по модам; одновременная достижимость минимальных рангов Таккера; оценка приближения усечённого HOSVD.

**Алгоритмы и конструкции:** HOSVD по ведущим левым сингулярным векторам развёрток по модам; усечённый HOSVD.

## Лекция 14. Тензорные сети, тензорные поезда и иерархический формат Таккера

**Описание:** Диаграммы тензорных сетей дают графический язык для структурированных многомерных представлений. Тензорные поезда, TT-SVD и иерархический формат Таккера заменяют экспоненциально большие тензоры сетями малых ядер, размеры которых контролируются рангами развёрток.

**Определения:** Диаграмма тензорной сети; свёртка; разложение в тензорный поезд; ядро тензорного поезда; матричное произведение состояний; TT-ранг; последовательная развёртка; иерархическое разложение Таккера.

**Теоремы и результаты:** Оценка ошибки усечённого HOSVD; минимальные TT-ранги как ранги последовательных развёрток; одновременная достижимость минимальных TT-рангов; оценка приближения TT-SVD.

**Алгоритмы и конструкции:** TT-SVD; построение дерева иерархического разложения Таккера.
